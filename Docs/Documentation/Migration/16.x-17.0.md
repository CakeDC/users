# Migration Guide from 16.x to 17.0

This guide describes the changes needed to upgrade your application from version 16.x to 17.0 of the CakeDC Users plugin.

## Version Requirements

- `cakedc/auth` **12.x**
- `cakephp/authentication` **4.2 or higher**
- CakePHP **5.3 or higher**
- PHP **8.1 or higher**

## Identifier Configuration

Identifiers now use the single-identifier format of `cakephp/authentication` 4.x. The collection
format keyed by identifier name is no longer supported.

**Old configuration (16.x):**

```php
'Auth.Authenticators.Form.identifier' => [
    'Authentication.Password' => [
        'fields' => [
            'username' => ['username', 'email'],
            'password' => 'password',
        ],
        'resolver' => [
            'className' => 'Authentication.Orm',
            'finder' => 'active',
        ],
    ],
],
```

**New configuration (17.0):**

```php
'Auth.Authenticators.Form.identifier' => [
    'className' => 'Authentication.Password',
    'fields' => [
        'username' => ['username', 'email'],
        'password' => 'password',
    ],
    'resolver' => [
        'className' => 'Authentication.Orm',
        'finder' => 'active',
    ],
],
```

Apply the same change to the `Token` and `Social` authenticators. `SocialPendingEmail` no longer
inherits the identifier from another authenticator; set it explicitly:

```php
'Auth.Authenticators.SocialPendingEmail.identifier' => [
    'className' => 'CakeDC/Users.Social',
    'authFinder' => 'active',
],
```

Dot-notation keys lose the identifier-name segment:

```php
// Before
'Auth.Authenticators.Form.identifier.Authentication.Password.fields.username' => 'email',
// After
'Auth.Authenticators.Form.identifier.fields.username' => 'email',
```

## URL Checkers

`Authentication.CakeRouter` no longer exists. Remove `urlChecker` from the `Form` and `Cookie`
authenticators; the default is `DefaultUrlChecker`. For a list of plain string URLs use
`Authentication.String` or `Authentication.Multi`.

## Password Rehash

The `Auth.PasswordRehash.identifiers` option was removed. Configure the authenticators that may
trigger a rehash:

```php
'Auth.PasswordRehash' => [
    'authenticators' => [
        'Form' => 'CakeDC/Users.PasswordLockout',
    ],
],
```

The identifier is the one configured in the authenticator; the array values are informational.

## Session Authenticator

`SessionAuthenticator` no longer supports the `identify` option. Use
`PrimaryKeySessionAuthenticator` when the identity must be read from the session.

## Removed APIs

- Global `Auth.Identifiers` configuration and `AuthenticationServiceLoader::loadIdentifiers()`.
- `AuthenticationService::loadIdentifier()` and `AuthenticationService::identifiers()` from
  `cakephp/authentication`.
